## 0.0.1

* Support HTTP and HTTPS URLs through the existing `MultiAssetPlayer`
  constructor.
* Display remote images, documents, media, HTML, and structured text without a
  separate network API.
* Add search and match highlighting to CSV and JSON viewers.
* Show elapsed and total time in audio and video players.
* Add interactive HTML and HTM asset playback using a JavaScript-enabled
  WebView.
* Add an example HTML asset with semantic tags and JavaScript interaction.
* Add the `MultiAssetPlayer` extension-based asset viewer.
* Support raster images, SVG, searchable text, and structured JSON.
* Add automatic viewer selection, loading errors, and unsupported-format UI.
